## Один переключатель: что уходит о сессии

Вместо четырёх уровней — одна галочка `sessions: true`; что уходит о сессии, решает режим её репозитория.

| Репозиторий сессии | Что уходит |
|---|---|
| `text` | минутные отметки промптов, ключ проекта и **заголовок** — если Worker разрешил текст, в сессии есть человеческий промпт не раньше `titlesSince` и файл записи сессии ещё существует |
| `counters` | отметки и ключ проекта, без заголовка |
| `off` | **ничего** — ни время, ни проект |
| GitHub-репозиторий | отметки и ключ `gh:<хеш owner/name>`; *принятое допущение:* заголовка нет до I5 — у такого репозитория нет режима |
| вне любого репозитория; необъявленный сервер; неполный клон | ничего (счётчик `promptsSkippedScope`) |

## Что читается из файлов сессий

Формат файлов внутренний и может измениться, поэтому читатель терпимый: берёт несколько полей, а непонятное
пропускает и считает.

- **Что читается.** Каталог `CLAUDE_CONFIG_DIR`, иначе `~/.claude`; только файлы `projects/<slug>/<36 hex и дефисов>.jsonl`
  верхнего уровня; построчно, `JSON.parse` в try/catch; из записи берутся только `type`, `timestamp`, `uuid`,
  `isSidechain`, `origin.kind`, `promptSource`, `entrypoint`, `cwd` (только в памяти), `aiTitle`.
- **Человеческий промпт** = `type: "user"`, `origin.kind === "human"`, без `toolUseResult`, `promptSource` ∈ {typed,
  suggestion_accepted}; `entrypoint: "sdk-cli"` исключается; дубли снимаются по `uuid` через все файлы. Примерно в 15%
  файлов `origin` нет вовсе — они пропускаются и считаются (метрика занижает, но не угадывает).
- **Кэш.** Записи сессий живут 30 дней, поэтому увиденные отметки и ключ проекта хранятся в `prompt-cache.json`.
  **Заголовки не кэшируются:** удалили сессию — её заголовок перестаёт отправляться со следующего `push`.
- Не проверено, нужны образцы при реализации: как выглядит `/compact` в текущих версиях; сохраняют ли копии при
  `--fork-session` исходные `uuid`. Тестовые данные в публичном репозитории — только синтетические.

## Метрика «время в паре с ИИ»

Метрику считает Worker, а не collector: определение одно на все версии collector'а, и к часам она не прибавляется
никогда.

- Соседние промпты с паузой ≤ 15 мин — один интервал `[первый, последний + 5 мин]`; интервалы всех машин
  объединяются; в зачёт идут только минуты, которых ещё нет в `covered` журнала учтённого
  ([07-selection.md](07-selection.md#журнал-внутри-state)).
- В отчёте — отдельная строка «время в паре с ИИ», разбивка по проектам, «из них N ч в сессиях без коммитов» и раздел
  «Сессии без коммитов» с заголовками там, где они разрешены.
- В часы, оценку зарплаты и серию недель метрика **не входит**; поведение по режимам приватности — в
  [01](01-architecture.md#слияние).
