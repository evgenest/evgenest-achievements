# Локальная LLM на текущем VPS

Дата оценки: 2026-09-12. Статус: **отклонено** (см. журнал решений в [README](README.md)).

## Идея

Держать локальные копии всех репозиториев на VPS (серверу доверяем полностью) и делать весь пайплайн локально:
сбор коммитов/PR/issues → обезличивание → написание отчёта. Облачная LLM не нужна вообще, данные не покидают сервер.

## Железо (замерено)

| Ресурс | Значение |
|---|---|
| CPU | 2 vCPU AMD EPYC Genoa (Zen 4), AVX-512 + VNNI + BF16 |
| RAM | 3.8 ГБ всего, свободно ~2.2 ГБ (остальное — фоновые сервисы и сессии агентов), swap 4 ГБ |
| GPU | нет (KVM, эмулированный VGA) |
| Пропускная способность памяти | ~8.5 ГБ/с на 1 потоке, ~17 ГБ/с на 2 потоках (самописный read-бенчмарк, 64 МБ массивы) |
| Диск | ~58 ГБ свободно, запись ~1.1 ГБ/с |

На CPU скорость генерации упирается в пропускную способность памяти: грубо `ток/с ≈ ПСП / размер весов`.

## Объём задачи

- Системный промпт (`src/i18n/ru.ts`) ~7 КБ + `DEV_PROFILE` ~2.6 КБ + JSON недели → **~6–12k входных токенов**.
- Выход: сводки по проектам + похвала + сообщение в Telegram → ~1–2k токенов (+ reasoning, если есть).
- Запуск раз в неделю, так что прогон на 5–15 минут допустим. Упор не во время, а в RAM и качество.

## Что влезает (оценка, не замер)

| Модель (Q4) | Веса + KV-кэш на ~10k токенов | Влезает | Генерация | Вывод |
|---|---|---|---|---|
| 1.5–2B | ~1.5 ГБ | да | ~10 ток/с, прогон ~5 мин | по времени ок, качество русского отчёта сильно ниже облачных моделей |
| 3–4B | ~3–4 ГБ | нет (только если остановить всё остальное — и то в swap) | ~4 ток/с | непрактично |
| 7–8B+ | 5+ ГБ | нет | — | — |

Для сравнения: понравившийся в отчётах `nvidia/nemotron-3-ultra-550b-a55b` — MoE на 550B параметров (55B активных),
в Q4 это порядка 300 ГБ весов. Локально такое повторяется только на сервере с несколькими GPU.

### Роль «препроцессор-обезличиватель» (вариант из #3)

Тоже на пределе: сюда влезает максимум ~2B, а маленькие модели ненадёжно находят приватное
(имена, суммы, внутренние названия). Без отдельной fail-closed проверки выхода (по аналогии с `assertSanitized`) небезопасно.

## Что сделало бы вариант рабочим (на будущее)

- **VPS с 16–32 ГБ RAM и 6–8 vCPU.** MoE-модели с ~3B активных параметров (класс Qwen3-30B-A3B, gpt-oss-20b, Nemotron 3 Nano 30B-A3B):
  скорость на CPU определяется активными параметрами, ожидаемо порядка 5–15 ток/с. Прогон раз в неделю — 5–15 мин. Стоимость апгрейда ~20–30 €/мес — отклонено.
- **Своя машина с GPU / Apple Silicon**, подключённая к серверу по приватной сети.
- Перед выбором конкретной модели — сверить размеры и требования по актуальным карточкам моделей (цифры выше — порядок величин).

## Архитектурная оговорка

Сейчас пайплайн работает в Cloudflare Worker и тянет данные через GitHub API. Полностью офлайн-вариант означает перенос
сбора данных и LLM на одну машину (с зеркалами репозиториев локально), а не просто замену провайдера LLM.
