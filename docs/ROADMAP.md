# Roadmap

> **Для кого:** любой, кто пришёл из публичного анонса и хочет узнать, что с обещанным; владельцу — оглавление.
> **Что здесь решает владелец:** ничего; все вопросы к нему — в [design/README.md](design/README.md#вопросы-владельцу).
> **Что просто к сведению:** всё — состояние трёх направлений и ссылки на их дизайн.

Что было анонсировано публично и в каком оно состоянии. Порядок пунктов — не обязательство; общий порядок работ,
сквозные принципы и вопросы владельцу — в [design/README.md](design/README.md).

| Направление | Состояние | Где описано |
|---|---|---|
| **Локальные источники** — git-репозитории вне GitHub и сессии Claude Code | Архитектура готова (пересмотрена 2026-09-19), код не начат | [design/local-sources/](design/local-sources/README.md) |
| **Тренды по неделям** — блок «На дистанции» в недельном отчёте | Архитектура готова, код не начат | [design/trends/](design/trends/README.md) |
| **Месячные и годовые ретроспективы** | Архитектура готова, код не начат | [design/retrospectives/](design/retrospectives/README.md) |

Тренды и ретроспективы стоят на общей основе — **записи недели** ([design/week-record/](design/week-record/README.md)):
маленькой машинной записи, которую недельный прогон кладёт в конец файла отчёта и в state. Она идёт первой, потому что
сырые события не хранятся по замыслу (снимок с машины живёт в KV не дольше 9 дней, файлы записи сессий Claude Code — 30 дней):
всё, что понадобится позже, записывается в момент сборки отчёта.

Анонсированный «демон на VPS, который сканирует локальные git-папки» в дизайне стал **программой командной
строки, которая запускается по расписанию**: демон — это ещё один постоянно живущий процесс на каждой машине, а отправка
раз в час, которую безопасно повторять (каждая заменяет предыдущую целиком), даёт то же без него.
