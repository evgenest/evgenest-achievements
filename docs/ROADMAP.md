# Roadmap

Что было анонсировано публично и в каком оно состоянии. Порядок пунктов — не обязательство.

| Направление | Состояние | Где описано |
|---|---|---|
| **Локальные источники** — git-репозитории вне GitHub и сессии Claude Code | Архитектура готова, код не начат | [design/local-sources/](design/local-sources/README.md) |
| **Тренды по неделям** | Идея | — |
| **Месячные и годовые ретроспективы** | Идея | — |

Анонсированный «демон на VPS, который сканирует локальные git-папки» в дизайне стал **CLI по
расписанию**: демон — это ещё один постоянно живущий процесс на каждой машине, а идемпотентный
push раз в час даёт то же без него.

Для трендов и ретроспектив долговечная единица — недельный агрегат и сам markdown-отчёт; сырые
события эфемерны по замыслу (KV 45 дней, транскрипты Claude Code 30 дней). Сейчас state хранит
52 снимка **прогонов**, не недель, и пять счётчиков на неделю — где держать агрегаты дольше, решает
дизайн ретроспектив.
